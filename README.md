# 贪吃蛇 · Git 学习项目

这是一个使用 HTML、CSS 和 JavaScript 制作的网页版贪吃蛇小游戏，同时用于练习 Git 和 GitHub 的基本工作流程。

## 功能

- 方向键或 WASD 控制移动
- 支持暂停和重新开始
- 自动保存最高分
- 根据得分逐渐加速
- 支持键盘、触屏按钮和滑动操作

## 运行方法

无需安装依赖，直接使用浏览器打开 `index.html` 即可运行。

## 操作方式

- 方向键或 WASD：控制方向
- 空格键：暂停或继续
- R：重新开始

## 学习内容

本项目用于练习：

- 初始化 Git 仓库
- 暂存和提交修改
- 创建与合并分支
- 连接 GitHub 远程仓库
- 使用 Pull Request 合并功能
